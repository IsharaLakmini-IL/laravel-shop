E-Commerce Web Application

Description

A full-stack e-commerce web application where customers can browse products,filter by category, add items to a shopping cart, and place orders with a shipping address. An admin panel allows the store owner to manage products,categories, and orders from a dedicated dashboard.Built as an undergraduate individual project using the Laravel MVC framework.

Technologies

                    PHP 8.2
                    Laravel 11
                    MySQL
                    Tailwind CSS
                    Laravel Blade
                    XAMPP 

Features

                     Customer Side
                        User registration and login (custom authentication — no starter kit)
                        Browse all products with category filter and search
                        Product detail page with size variant selector (XS, S, M, L, XL, XXL, XXXL)
                        Individual stock tracking per size variant
                        Shopping cart (add, update quantity, remove items)
                        Checkout with shipping address
                        Order placement with automatic stock decrement
                        Order history and order detail view

                    Admin Side
                         Secure admin panel (protected by role-based middleware)
                         Secure admin panel (protected by role-based middleware)
                         Dashboard with total products, orders, revenue and pending order stats
                         Full product management (create, edit, delete with image upload)
                         Size variant management with stock per size
                         Category management (create, edit, delete)
                         Order management with status update (pending, processing, shipped, delivered, cancelled)    

What I Learned
                         MVC architecture pattern with Laravel
                         Database design with foreign key relationships
                         Role-based access control using custom middleware
                         File uploads with Laravel Storage
                         Git branching workflow and version control
